# Support

Where a question should go.

| You have | Take it to |
|:--|:--|
| A fault in a repository | An issue on that repository, using the fault form |
| An idea for a repository | An issue on that repository, using the proposal form |
| A weakness | [The security policy](SECURITY.md). Never a public issue |
| A concern about someone's conduct | [contact@bit-trading-company.com](mailto:contact@bit-trading-company.com), in confidence |
| A partnership, or anything else | [contact@bit-trading-company.com](mailto:contact@bit-trading-company.com) |

## What to expect

These repositories are kept by a small number of people. Every message is read by one of them. Replies are not immediate and are not guaranteed, and a reply drafted by software will say that it was.

Nothing in these repositories is financial, legal or tax advice, and no question put here will be answered as though it were.
